\section{Introduction}
\label{sec:intro}

This document is a collaborative LaTeX project designed for real-time editing via VS Code Live Share.
All team members can edit \texttt{.tex} files simultaneously, and the PDF is automatically compiled and
shared via HTTP whenever any file is saved~\citep{latexcompanion}.

The goal is to provide a zero-configuration experience for Guests: they only need VS Code and the
Live Share extension to join the session and see the latest PDF in their browser.

\section{Results and Discussion}
\label{sec:results}

The workflow demonstrated here enables:

\begin{itemize}
    \item Real-time collaborative editing via Live Share.
    \item Automatic compilation on every save via \texttt{latexmk}.
    \item Instant PDF preview through a shared HTTP server.
\end{itemize}

Table~\ref{tab:comparison} compares the roles in this setup.

\begin{table}[htbp]
    \centering
    \caption{Role comparison in the collaborative workflow.}
    \label{tab:comparison}
    \begin{tabular}{l|l}
        \hline
        \textbf{Role} & \textbf{Responsibility} \\
        \hline
        Host   & Runs the SSH server, triggers build, shares port \\
        Guests & Edit \texttt{.tex} files, refresh browser for PDF \\
        \hline
    \end{tabular}
